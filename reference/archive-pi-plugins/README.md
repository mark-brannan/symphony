# Archived Pi plugin configs

Config data for 3 SignalK plugins used on the old bare-metal Pi deploy, not
present in the current `signalk/` config. Likely dead; kept only so they
aren't lost when dotfiles' `archive/signalk-pi/` history is dropped via
filter-repo.

- `set-system-time.json`
- `signalk-healthcheck.json`
- `signalk-rpi-uptime.json`

Source: `mark-brannan/dotfiles` `archive/signalk-pi/plugin-config-data/`,
copied at commit bcf104b (dotfiles HEAD 2026-08-20).
