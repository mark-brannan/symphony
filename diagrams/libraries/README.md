# Shape libraries

- `symphony-shapes.xml` — draw.io shape library holding only the shapes
  Symphony's diagrams actually use. Load via File → Open Library in
  draw.io/diagrams.net. Curated 2026-08-19 from the community Victron
  library (source:
  [MERKAT0R/Victron-Shapes-Public](https://github.com/MERKAT0R/Victron-Shapes-Public),
  originally by "D S" on the Victron Community "Visio stencils" thread).
  Add shapes here only when a diagram starts using them; the full 15 MB
  library stays out of the repo.
